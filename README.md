## Abstract

This speculative CIF case study examines the Great Pyramid of Giza as a thought experiment in deep-time information preservation. It does not treat intentional geodetic encoding as established archaeology. Instead, it analyzes the distinction between preserving physical data and preserving meaning, method, uncertainty, warnings, and stewardship across civilizational discontinuity.
